 
Application Angular permettant aux administrateurs de créer et gérer des templates de formulaires PDF personnalisés, et aux utilisateurs de remplir ces formulaires en ligne.
 

## 📦 Installation

```bash
# Installer les dépendances
npm install

# Lancer le serveur de développement
ng serve

# L'application sera accessible sur http://localhost:4200
```
